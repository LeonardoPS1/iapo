La integración con la API oficial de WhatsApp es más estable y la recomendamos
para volumen alto, pero Evolution resuelve rápido cuando el requisito es no
pagar por mensaje y controlar la sesión. Ojo con el mantenimiento de la sesión y
con el uso responsable: mandar plantillas masivas por acá es la forma más rápida
de que te bloqueen el número.
