Cuando un agente falla, el log plano no alcanza: necesitás ver el prompt que
entró, la respuesta cruda, las herramientas llamadas y el costo. Langfuse
guarda todo eso y permite comparar versiones de un prompt con un dataset fijo,
que es la única forma seria de saber si un cambio mejoró algo.
